## Opening post

Could the organizers clarify how the training-code delivery requirement in
section 2.8 applies to permitted, publicly available third-party pretrained
weights used unchanged in a solution?

If the original training source for those third-party weights is not available
in a complete, legally redistributable form, can winner delivery satisfy that
requirement with the pinned weight sources, versions and licenses, the exact
inference code and environment, and a reproducible description of their use?
Or must complete, legally redistributable training source for those third-party
weights also be provided?

This question concerns the scope of the winner-delivery requirement, not a
request for an exception. We understand that permission to use external models
does not by itself waive the other rules, and that licensing of pretrained
inputs and delivery of reproducible code are separate obligations.
